
# Login Page - Manual Testing

## Overview

This project contains manual test cases created for testing a Login page.

The test cases are designed to practice functional, negative, validation, usability, and security-related testing scenarios.

## Test Coverage

The Login test suite contains 20 test cases covering:

1. Valid email and valid password
2. Valid email and invalid password
3. Invalid email and valid password
4. Invalid email and invalid password
5. Blank email with valid password
6. Valid email with blank password
7. Both fields blank
8. Unregistered email with valid password
9. Email without `@`
10. Email without domain
11. Password case sensitivity
12. Password masking
13. Leading/trailing spaces in email
14. Very long email
15. Very long password
16. Special characters in password
17. Forgot Password link
18. Login button behavior
19. Multiple failed login attempts
20. Successful login after failed attempt
